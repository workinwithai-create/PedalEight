# PedalEight

Eight-bar pedal-point desk for bedroom producers and AI-music finishers.

Suno and loop desks change every chair with every chord. The section never sits, so the song never finishes. PedalEight writes the eight bars where upright bass and cello hold one note — the key root, or the fifth — while piano and flute move the progression above them. A is the moving print. B is the pedal. The chorus starts the bar after this file ends.

Live samples only. Acoustic grand and upright from PreEight commit `d58301e4a494555f411a2afbc448b724136eee76`. Cello and flute from FluidR3_GM commit `044fab8e1456bfafc5776e86dfd6bb8697149aef`. Kit is the acoustic kick, snare, and hat from the same PreEight pin. No oscillators. Audio never leaves the tab.

This GitHub build is **free**.

## Distinct from the line

| Tool | Job |
| --- | --- |
| AirCut | Subtractive eight bars so the drop has air |
| PickBar | Anacrusis pickup on the and-of-4 |
| LandFour | Cadence that sits the loop down at the end |
| OrganFour | Organ color on a stuck loop |
| FloorEight | Breakdown floor so chorus 2 has a door |
| HookGrid | Stamp the song map |
| **PedalEight** | One note held in bass and cello while the chords move |

Yesterday’s ship was AirCut. PedalEight is not a cut and not a pickup. It is gravity: the chairs that should not move.

## Loop

1. Set BPM (60–180), key, and four chords. They persist in this browser.
2. Hear A: the moving print.
3. Stamp a pedal recipe.
4. Hear B. Changes land on the next step.
5. Export the looped WAV (tail folded to sample 0) and a matching MIDI, one chair per track.

Space plays. `1` is print, `2` is pedal. iOS silent switch mutes Web Audio. This is not a keyboard instrument.
